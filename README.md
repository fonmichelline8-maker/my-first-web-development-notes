## What is a client?

A client is the device or browser that asks for something.
For example, your phone or Chrome browser can be a client

## What is a server?

A server is a computer that receives requests and sends back information.
It works behind the scenes

## What happens when someone visits a website?

First, the person enters the website address.
DNS helps find the server.
The browser then sends a request to the server.
The server processes it and sends a response.
The browser displays the website.

## What is the Internet?

The Internet is a huge network that connects computers and devices around the world.
It allows them to communicate and share information

## What is DNS?

DNS means Domain Name System.
It helps turn a website name into an IP address.
This helps the browser find the right server

## What is HTTP?

HTTP means HyperText Transfer Protocol.
It is a set of rules that helps browsers and servers communicate.
It allows requests and responses to move between them
## What is HTTPS?

HTTPS is the secure version of HTTP.
It helps protect information sent between the browser and the website.
It is especially important for passwords and payment details

## What is the difference between frontend and backend?

The frontend is what the user sees and interacts with.
It includes things like buttons, text, images, and pages

The backend works behind the scenes.
It handles things like logins, requests, and application logic.

## What is Git?

Git is a tool used to track changes in code.
It helps developers keep a record of their work.
It also makes it easier to go back to an earlier version

## What is GitHub?

GitHub is an online platform where developers can store and manage their code using Git.
It also makes it easier to share and work on projects with others
